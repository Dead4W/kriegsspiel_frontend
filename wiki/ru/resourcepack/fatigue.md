## `fatigue`

Путь: `fatigue`

Усталость — необязательное правило комнаты. Когда настройка комнаты **«Усталость»** включена, юниты накапливают усталость во время движения и боя. Она снижает урон и может снижать скорость.

Значение усталости ограничено диапазоном от `0` до `max`.

---

## ФОРМАТ

```json
{
  "fatigue": {
    "max": 10,
    "attackHoursPerPoint": 1,
    "moveHoursPerPoint": 0.5,
    "recoveryPerHour": 1,
    "attackedRecoveryMultiplier": 0.5,
    "damageCurvePower": 5,
    "speedThresholds": [
      { "moreThan": 5, "multiplier": 0.8 },
      { "moreThan": 8, "multiplier": 0.6 }
    ]
  }
}
```

## ГЛОБАЛЬНЫЕ ПАРАМЕТРЫ

- `max` — максимальная усталость.
- `attackHoursPerPoint` — часы активного боя для накопления одной единицы усталости.
- `moveHoursPerPoint` — часы фактического движения для накопления одной единицы усталости.
- `recoveryPerHour` — сколько усталости восстанавливается за час бездействия.
- `attackedRecoveryMultiplier` — множитель восстановления в шаге хода, когда юнит получил урон.
- `damageCurvePower` — форма кривой штрафа урона.
- `speedThresholds` — упорядоченные пороги усталости. Применяется множитель `multiplier` первого превышенного порога.

Движение и бой могут происходить в одном шаге: накопление от них суммируется. Усталость восстанавливается, только когда юнит не движется и не атакует. Отступающие юниты не восстанавливают усталость.

## КРИВАЯ УРОНА

Множитель урона вычисляется по формуле:

```text
1 - (fatigue / max) ^ damageCurvePower
```

При максимальной усталости урон всегда равен `0`. Степень больше `1` делает ранний штраф небольшим, но сильнее снижает урон вблизи максимума.

## МОДИФИКАТОРЫ ЮНИТА

В `units.types[].params` можно указать числовые параметры:

- `fatigueAccumMult` — множитель накопления усталости от движения и боя.
- `fatigueRecoveryMult` — множитель восстановления в бездействии.

Пример для морпехов, которые устают вдвое медленнее:

```json
{
  "id": "marine",
  "params": {
    "fatigueAccumMult": 0.5
  }
}
```

## ФОРМАЦИИ И СПОСОБНОСТИ

Задайте `multipliers.fatigue` у формации или способности, чтобы изменить накопление усталости, пока она активна.

```json
{
  "id": "onHorse",
  "multipliers": {
    "fatigue": 0.5
  }
}
```

Этот же принцип работает для способностей: `fatigue: 2` удваивает накопление усталости на время действия способности.

## ОКРУЖЕНИЕ

Состояния окружения поддерживают оба параметра:

- `params.fatigueAccumMult`
- `params.fatigueRecoveryMult`

Пример дома, который вдвое уменьшает накопление и вдвое ускоряет восстановление:

```json
{
  "id": "in_house",
  "params": {
    "fatigueAccumMult": 0.5,
    "fatigueRecoveryMult": 2
  }
}
```
